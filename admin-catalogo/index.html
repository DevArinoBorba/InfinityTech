Atualizar catálogo

Envie o relatório de estoque do sistema — os preços do site são trocados na hora.

1. Escolha a planilha

O arquivo que o sistema exporta, do jeito que ele sai (.xlsx ou .csv). Não precisa editar nada antes.

Arraste a planilha aqui ou clique para procurar no computador

2. Confira o que vai mudar

Comparação entre a planilha enviada e o catálogo que está no ar agora. Nada foi publicado ainda.

3. Publicar

As categorias já cadastradas são mantidas automaticamente — só os preços e a lista de produtos são trocados.

Como funciona

  1. A planilha é lida aqui no navegador — nada é enviado enquanto você não confere a prévia.
  2. Ao publicar, a lista de produtos e os preços da planilha do catálogo são reescritos.
  3. A categoria de cada produto é preservada pelo nome. Produto que aparece pela primeira vez recebe uma categoria sugerida pelo nome, que pode ser corrigida direto na planilha depois.
  4. O site leva até 5 minutos para mostrar os preços novos (cache do Google).
